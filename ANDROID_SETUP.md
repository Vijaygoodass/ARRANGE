# 🤖 Android Setup Instructions

## Quick Start (5 Minutes)

### 1️⃣ Download Pre-built APK

```bash
# After I build it, download from:
# https://github.com/Vijaygoodass/ARRANGE/releases

# File: arrange-1.0-debug.apk
```

### 2️⃣ Install on Phone

1. Transfer APK to phone
2. Open file manager
3. Tap the APK file
4. Select "Install"
5. Done! ✅

---

## Required Permissions

The app requests these permissions:
- ✅ **Read External Storage** - To scan files
- ✅ **Write External Storage** - To move/organize files
- ✅ **Manage External Storage** - For Android 11+ (full file access)

**Grant these when app first launches!**

## Using on Android

### Add Directory:
```
1. Tap "➕ Add"
2. Enter path: /storage/emulated/0/Download
3. Tap "✓ Add"
```

### Start Organizing:
```
1. Select directory from dropdown
2. Tap "⚡ Organize Now"
3. Watch files get organized
4. Check log for details
```

### View Settings:
```
1. Tap "⚙️ Settings"
2. See directories and info
3. Tap "Close"
```

## 🆘 Troubleshooting

### Permission Error
**Problem:** "Permission denied" when organizing

**Solution:**
```
1. Go to Settings
2. Apps > ARRANGE
3. Tap Permissions
4. Enable "Files and Media"
```

### Can't Find Directory
**Problem:** Path not working

**Solution:**
- Use: `/storage/emulated/0/` instead of `/sdcard/`
- Check exact folder name in file manager
- Copy-paste path to avoid typos

### App Won't Install
**Problem:** Installation fails

**Solution:**
```
1. Settings > Security > Unknown Sources
2. Enable "Allow installation from unknown sources"
3. Try again
```

### App Crashes
**Problem:** App closes immediately

**Solution:**
- Update Android OS (Settings > System > System Update)
- Uninstall and reinstall app
- Check storage space (needs 100+ MB)
